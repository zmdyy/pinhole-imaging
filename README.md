# 小孔成像 · 交互教学演示

面向初中物理课堂的小孔成像 HTML 教学工具。当前版本为纯前端单文件实现，不依赖外部框架或图片资源。

## 当前功能

- 3D 装置观察：物体、小孔板、暗箱、光屏同时存在，可拖动旋转视角。
- 2D 正交剖视：与 3D 共用同一组实验状态，用于解释光路。
- 右侧独立“从观察侧看光屏”窗口。
- 显示物体高度与像的高度，不显示物距、像距数值。
- 物点光路：顶部/底部物点可直接点击，也可用按钮选择；展示发散光、遮挡与通过小孔的光束。
- 小孔大小探究：孔变大时亮度提高、几何模糊增大；孔变小时亮度降低、清晰度提高。
- 小孔形状：圆形 / 方形 / 正三角形，切换时保持孔面积相同。
- 光屏材料：透明膜 / 半透明膜 / 不透明膜；可切换观察侧与受光面。
- 暗箱剖视：明确标注为“教学剖视”，避免误认为真实暗箱透明。
- 结构拆解：小孔片、暗箱筒体、光屏、固定圈沿光轴分离，拆解状态暂停成像光路，避免把结构观察误认为实验状态。
- 3D 材质增强：暗箱改为深色哑光圆筒，固定圈增加厚度；透明、半透明、不透明光屏使用不同的表面纹理与高光表现。
- 3D 空间光束：穿孔光线同时在横向和纵向展开，不再只用同一平面的三条线表示。
- 物体：蜡烛 / 箭头 / 字母 F。
- 六个教学入口：成像原因、倒立、孔大小、孔形状、光屏材料、自由探索。
- 全屏模式，适合教室大屏。

## 使用

直接打开 `index.html` 即可。建议使用最新版 Chrome / Edge。

## 教学说明

该版本采用几何光学近似。极小孔径时的衍射不是当前主线，页面仅作提示，不参与主要模型计算。
